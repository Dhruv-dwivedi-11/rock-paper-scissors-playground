# Rock Paper Scissors Game 🎮

A simple and interactive Rock Paper Scissors game built using **HTML**, **CSS**, and **JavaScript**. Challenge the computer and see if you can win!

## 🕹️ Features

- Clean and responsive user interface
- Randomized computer choice
- Real-time game result display
- Score tracking
